REDLINE APK - BUILD STEPS
1. Create a free account at github.com and make a new repository (name it redline, set it Public or Private).
2. Upload ALL files from this folder into the repository (including the .github folder).
   If .github does not upload: in GitHub click Add file > Create new file, name it
   .github/workflows/build.yml and paste the contents of build.yml.
3. Open the Actions tab, pick "Build APK", click Run workflow. Wait 5 to 10 minutes.
4. Open the finished run, download the Redline-APK file at the bottom, unzip it to get app-debug.apk.
5. Send app-debug.apk to phones. On each phone tap it and allow "install from unknown sources".
